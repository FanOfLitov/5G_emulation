# План научной работы

## Тема

Эмуляция 5G сети в виртуальной Linux-среде с использованием контейнеризации и собственного программного модуля анализа сетевых характеристик.

## Цель работы

Разработать виртуальную среду для исследования принципов функционирования 5G SA сети и создать программный модуль для измерения сетевых характеристик.

## Задачи

1. Изучить архитектуру 5G SA сети.
2. Развернуть виртуальную Linux-среду на базе WSL Ubuntu.
3. Настроить контейнерную инфраструктуру Docker.
4. Подготовить компоненты 5G Core.
5. Подключить эмулятор gNodeB и UE.
6. Разработать C-модуль для анализа сетевых характеристик.
7. Провести эксперименты по измерению latency, jitter, packet loss и throughput.
8. Проанализировать результаты и сделать выводы.

## Объект исследования

Виртуальная программно-эмулируемая 5G сеть.

## Предмет исследования

Методы эмуляции 5G-сетей и измерения сетевых характеристик в контейнерной среде.

## Используемые технологии

- WSL Ubuntu
- Docker Desktop
- Docker Compose
- Open5GS
- UERANSIM
- C
- GitHub
- CSV logging

## Собственный программный вклад

В рамках работы разработан C-модуль, включающий:

- измерение задержки;
- расчёт jitter;
- расчёт packet loss;
- генерацию UDP-трафика;
- приём UDP-трафика;
- расчёт throughput;
- сохранение результатов в CSV.
