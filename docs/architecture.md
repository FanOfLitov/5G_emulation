## Текущий этап

На первом этапе поднимается MongoDB как база данных для будущего Open5GS Core.

Компоненты:

- `open5gs-mongodb` — база данных;
- `open5gs-mongo-express` — веб-интерфейс для просмотра MongoDB.

Адрес Mongo Express:

```text
http://localhost:8081



## C-модуль измерений

Собственный модуль на языке C выполняет:

- генерацию ICMP-запросов;
- измерение сетевой задержки;
- логирование результатов;
- подготовку данных для анализа качества сети.

Результаты сохраняются в CSV-формате.
